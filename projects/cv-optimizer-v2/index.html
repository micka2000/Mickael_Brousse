The starting pointLe point de départ

I built it to optimise my CV for ATS in my job search.Pour optimiser l’ATS dans mes recherches d’emploi.

Mickaël Brousse

In shortEn bref

  • Job search from the CV: Claude derives search queries from the profile, Adzuna returns real listings.Recherche d’offres depuis le CV : Claude déduit les requêtes du profil, Adzuna renvoie de vraies annonces.
  • Ranking by ATS keyword match, distance from home, salary and recency, with matching and missing keywords on each offer.Classement par correspondance ATS, distance du domicile, salaire et fraîcheur, avec les mots-clés présents et manquants pour chaque offre.
  • Tailored CV: Claude rewrites the CV for the chosen offer, then a proofreading pass checks it.CV sur mesure : Claude réécrit le CV pour l’offre choisie, puis une passe de relecture le vérifie.
  • ATS score that is checked, not claimed: the rendered CV is scored against the posting with a fixed, weighted formula, instead of letting the model grade itself.Score ATS vérifié, pas déclaré : le CV produit est noté face à l’offre avec une formule pondérée fixe, au lieu de laisser le modèle s’auto-évaluer.
  • One-page PDF rendered in a headless browser, ready to send.PDF d’une page rendu dans un navigateur sans interface, prêt à envoyer.
